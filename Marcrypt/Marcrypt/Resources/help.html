Marcrypt Help

Batch encryption, watermarking, and Bates numbering for PDF, Word, and folders — entirely on your Mac. Nothing is ever uploaded.

Marcrypt never connects to the internet. All processing happens locally on your machine.

Getting started

  1. Drag PDF, DOCX, ZIP, or folders onto the drop zone (or click to browse).
  2. Review the file list — Marcrypt detects which items are already encrypted.
  3. Set a password and click Encrypt, or use Decrypt for protected files you have the password to.

Encryption

PDF

PDFs are encrypted with a password to open. The owner (permissions) password is always set to a value distinct from your open password, so opening the file does not grant full permission rights.

Word (DOCX)

Word documents are encrypted using Microsoft's Office Agile Encryption (AES-256, MS-OFFCRYPTO). The result opens natively in Microsoft Word with the password you set.

Folders & ZIP

Folders are archived into a password-protected ZIP using WinZip AES-256.

Watermarks & Bates numbering

Add a text watermark (e.g. CONFIDENTIAL) and/or sequential Bates numbers to PDFs and DOCX files. Configure text, size, opacity, color, and placement in Settings. Bates numbering continues sequentially across a batch for legal-discovery workflows.

Word editing restrictions

Read-only, comments-only, tracked-changes, and form-fill restrictions can be applied to DOCX files.

Editing restrictions are advisory. They are honored by Microsoft Word but can be bypassed by other editors. Use document encryption when you need real confidentiality.

Stripping metadata

Optionally remove identifying metadata (Author, Title, Company, Producer, and similar) from PDF and DOCX files before encrypting. Originals are left untouched unless you enable "Overwrite & Remove Original Files."

Removing originals & Clear History

"Overwrite & Remove Original Files" overwrites a file before deleting it.

Overwrite-based deletion is best-effort. On modern SSDs and APFS, wear-leveling and copy-on-write can leave earlier data blocks beyond any application's control. Treat it as convenience cleanup, not guaranteed forensic erasure.

Clear History (in Settings) removes app logs, audit history, temporary processing files, dropped-file staging, and the current file list.

Forgotten passwords

Marcrypt can try a short list of common passwords against a file you own but can no longer open. This is a convenience for recovering your own documents — it is not a cracking tool and will not defeat a strong password.

Privacy & security

  • 100% local processing — no network access, by design.
  • Standard, audited cryptography (AES-256 via Apple frameworks).
  • Audit logging and verbose diagnostics are off by default and can be cleared at any time.
